# Asset sources and provenance

Every image GOATerizer ships is recorded here: what it is, who made it, and
under what licence. `AGENTS.md` §11 requires this even where attribution is not
legally required.

Nothing is hotlinked at runtime. All art is stored under `public/assets/` and
served by this project.

---

## Rocky Ascent, and its three companions — placeholder art (CURRENT)

`scripts/generate-placeholder-art.mjs` generates all four scenarios from one
set of shared drawing functions in `scripts/lib/rocky-art.mjs`: a goat pose
cycle, a foothold, a destination cairn, a dust puff, a tick glint, and a
mountain backdrop. Rocky Ascent High, Rocky Descent and Rocky Descent High
reuse that same set rather than each getting distinct art, because their own
scenario files say to: each names `"Placeholder source families may be reused
from the normal version; final art can distinguish the high version later"`
(Rocky Descent's file states the same intent for reusing Rocky Ascent's
families). Only the background and dust carry a per-family RNG seed, so the
four are not byte-identical files while still reading as one consistent set;
re-running the generator reproduces every file byte for byte.

Every asset id below follows `<kind>_<scenario id>[_suffix]` — swap
`rocky_ascent` for `rocky_ascent_high`, `rocky_descent`, or
`rocky_descent_high` (and the directory for the matching
`public/assets/scenarios/<dir>/`) to get any companion's table.

  `bergschaf-bocksprung-f.png` (same layout) — row 2, column 1, a goat reared

  (`scripts/lib/rocky-art.mjs:44`), so every frame was mirrored — see Edits.
- **Edits:** for each frame — cropped to the raw 63×63 grid cell, trimmed to
  the opaque (alpha > 8) bounding box, mirrored horizontally to face right,
  then downsampled (canvas `imageSmoothingQuality: "high"`, not
  nearest-neighbour) to a small crisp size (26px tall for the four advance
  poses, 30px tall for the taller reared-up finish pose) — the renderer draws
  with `imageSmoothingEnabled = false`
  (`src/ui/timeline/timeline-view.ts:580`), so, as with Goat Frontman's shipped
  art, a detailed source has to be pre-downsampled to the pixel grid it should
  read at. No colour was changed; the cream/tan coat and horn colour are the
  source's own, and already read as alpine rather than tropical. Both edits
  are within what CC-BY permits ("edits thereof"). The renderer does not
  require a fixed pixel size or matching dimensions across poses — it draws
  each `climberPoses[]` frame at the same fixed on-screen height and derives
  width from that frame's own aspect ratio (`src/ui/timeline/actor-layer.ts:342-345`),
  so nothing needed to be forced to exactly 24×18.
- **Why this and not a recolour or a different pack:** this repository's own
  house style (`scripts/lib/rocky-art.mjs`) already draws a cream-fur,
  tan-horn, no-black-keyline quadruped goat — the same coat this pack ships —
  so no recolour was needed (contrast Goat Frontman, which *did* need one and
  rejected it as unworkable; see that branch's `ART_SOURCING_FINDINGS.md` §2).
  No other pack found in this session's search (§ below) had a usable
  quadruped side-profile goat at any licence.
- **In the shipped build:** CC-BY requires the attribution to travel with the
  work, not just live in this doc, so it is duplicated at `public/CREDITS.txt`.
- **Known gap this session did not close:** the four scenario JSON files
  (`docs/scenarios/rocky-ascent*/`, `docs/scenarios/rocky-descent*/`) still
  list `placeholderSourceId: "spring_goat_ram"` and the old
  `sourceSelection`/`runtimeNotes` text for these five asset ids per scenario.
  That's stale now that real art ships from a different source under a
  different licence, but this task was scoped to asset files and this doc, not
  scenario JSON — a future session should update those fields to point at
  `oga_mountain_goat` (below) and correct the licence note.

### Why the old placeholder-source claim didn't hold

`docs/scenarios/rocky-ascent/rocky_ascent.scenario.json` named four
third-party CC0 packs as the intended placeholder sources, including
`spring_goat_ram` for the goat pose cycle. A previous session recorded that
its own environment could not reach `itch.io` or `opengameart.org` at all, so
none of the four could be verified from there.

This session's environment reaches both hosts. Direct `curl` to each root
returned `200`, and every source page below was opened, read and (where
relevant) its actual sprite sheet inspected pixel-by-pixel — not judged from a
search snippet or a stated licence alone. `spring_goat_ram` specifically
**is not a quadruped goat**: opening `goat or ram_strip5.png` shows a bipedal,
armoured ram *warrior* — navy armour, heavy black keyline, holding an axe. Its
CC0 licence claim was correct; the art was simply wrong for this scenario. An
earlier session working on Goat Frontman independently opened the same file
for a different scenario and reached the identical conclusion (see that
branch's `ART_SOURCING_FINDINGS.md`) — this doc now records it here too so a
future session doesn't re-open that page a third time.

### How to swap in what's left

For `bg_rocky_ascent`, `prop_rocky_ascent_step`, `prop_rocky_ascent_goal`,
`fx_rocky_ascent_dust` and `fx_rocky_ascent_tick`:

1. Get the user's go-ahead before downloading anything from an itch.io
   `/purchase`-style page, even a nominally free one.
2. Download from the source page and re-verify the licence.
3. Extract the single frame(s) named above — the runtime treats every sprite
   as a **static billboard**, so strips, sheets and GIFs must be reduced to
   one frame each.
4. Save each as `public/assets/scenarios/<scenario dir>/<asset id>.png`,
   overwriting the generated placeholder — once per directory
   (`rocky-ascent/`, `rocky-ascent-high/`, `rocky-descent/`,
   `rocky-descent-high/`) you want to carry real art, using that directory's
   own asset ids.
5. Move that source's row into a shipped section of this file, with the
   licence you verified and the date you verified it.

No code change is needed: the asset ids and their slot bindings are scenario
data, and the runtime loads whatever is at those paths.

## Rules for any future asset

- Verify the source page and the licence before use; prefer CC0.
- Record source URL, author and licence here, even when attribution is not
  legally required.
- Store the file in this project; never hotlink at runtime.
- Do not introduce copyrighted commercial game assets as placeholders.
- Do not create many near-identical assets where a runtime transform or a
  duplicated instance produces the same result — one foothold sprite is
  instantiated up to thirty times per attempt, varied only by transform.
